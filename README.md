# Yoorel — Персонализированная книга зимних напитков

Интерактивный промо-лендинг и 5-шаговый конфигуратор персонализированной книги рецептов согревающих зимних напитков.

**Боевой сайт:** [https://yoorel.tilda.ws/](https://yoorel.tilda.ws/)

---

## 📖 О проекте

«Yoorel» — подарочная книга из 24 авторских зимних напитков и 1 уникального 25-го рецепта, создаваемого персонально для получателя на основе его вкусовых предпочтений.

### Ключевой функционал:
1. **Премиальный дизайн (Apple HIG / Unslop)**
   - Тёплая зимняя цветовая гамма (палитра сливочной карамели, тёмного шоколада и жжёной терракоты).
   - Интерактивная 3D-обложка с динамической подстановкой имени получателя в реальном времени.
   - Карусель разворотов книги с реалистичной тенью переплёта и кнопками навигации.
   - Интерактивный калькулятор/сравнение тарифов (Печатная книга 2 990 ₽ / Электронная PDF 990 ₽).
   - Аккуратный раскрывающийся FAQ и блок автора рецептов.

2. **5-этапный модальный конфигуратор**
   - **Шаг 1:** Имя получателя и выбор тональности обращения (на «Ты» / на «Вы»).
   - **Шаг 2:** Интерактивный опросник вкусов (любимый согревающий напиток + зимняя атмосфера) с 5-сегментным индикатором прогресса Apple.
   - **Шаг 3:** Персональное поздравление от шефа с автогенерацией текста, возможностью перегенерации или ручного редактирования.
   - **Шаг 4:** Загрузка фотографии получателя с возможностью предпросмотра и удаления.
   - **Шаг 5:** Мгновенный выбор формата издания с аппаратным GPU-ускорением (`transform: translateZ(0)`).

3. **Облачная интеграция с Яндекс.Диском**
   - При оформлении заказа прикреплённое фото автоматически отправляется через OAuth API в защищенную папку `disk:/Yoorel_Orders`.
   - Файл автоматически публикуется, а публичная ссылка на Яндекс.Диск передаётся в параметры заказа Тильды.

4. **Интеграция с корзиной Тильды (`ST100`)**
   - При нажатии «В корзину и к оформлению» создается товар с полным набором кастомных опций:
     - Имя получателя
     - Формат издания
     - Тон обращения
     - Выбранный вкус
     - Выбранная атмосфера
     - Полный текст персонального поздравления
     - Публичная ссылка на фото на Яндекс.Диске
   - Мгновенно открывается окно оформления заказа Тильды.

## 🛠 Структура файлов

- `index_optimized.html` — актуальная вёрстка лендинга со всеми стилями Apple HIG, разворотами книги и анимациями.
- `index.html` — автономный HTML-прототип для локального тестирования в браузере.
- `build_full_optimized.py` — главный билд-скрипт, собирающий лендинг + скрипт модального конфигуратора + интеграцию Яндекс.Диска и отправляющий код в Тильду через Tilda MCP API.
- `deploy_with_yadisk.py` — вспомогательный скрипт тестирования загрузки на Яндекс.Диск.
- `generate_optimized_code.py` — генератор объединенного HTML/CSS/JS бандла.
